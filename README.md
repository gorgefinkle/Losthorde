# Losthorde — Dead Streets

A standalone Paper 26.2 / Java 25 zombie horde plugin with an optional Metropolis integration.

**Status: R02 experimental development checkpoint.** The current implementation includes daylight-immune persistent walkers, shared 16-block-activation zombie spawners (instant first wave, randomized 30–60-second waves), floating countdowns, and a configurable danger-warning preview. Automatic migrating hordes, district-flag activation, road routing, live horde warnings, and multiplayer no-pop-in tests are not complete.

The initial source, tests, and Metropolis R14_5D integration patch are being prepared for this repository. Paper runtime behavior has not yet been verified.
