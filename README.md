# Losthorde / Dead Streets

Experimental Paper 26.2 / Java 25 zombie population, migration, and special-infected plugin, with optional Metropolis BUILD population integration.

**R14** introduces optional BetterModel 3.7.1 visuals for the horizontal Crawler and broad three-block Hulk, plus per-player aimed identity/health displays.

## Server requirements

- Paper 26.2
- Java 25
- Dead Streets R14
- BetterModel 3.7.1 recommended for the custom Crawler and Hulk visuals (optional; vanilla fallback remains visible without it)

BetterModel builds and delivers its own resource pack. Players must accept the pack to see the custom models. No client mod is required. Metropolis integration remains optional and file-based.

## Special infected

- **Crawler:** Real Zombie gameplay entity with a fixed compact swimming-pose hitbox and a horizontal animated Blockbench model. The previous vanilla swimming pose alone rendered upright; R14 replaces that failed visual with BetterModel's deadstreets_crawler model and crawl animation.
- **Hulk:** Real Zombie with native scale 1.53846 and a measured three-block bounding box, plus a broad BetterModel zombie model and heavy_walk animation.
- **Runner:** Retains its existing fast movement and combat tuning.
- **Popper:** Retains its death burst, modest player damage, and release of 1–4 Crawlers.

The server-side Zombie remains authoritative for AI, navigation, targeting, collision, health, damage, persistence, and death. BetterModel supplies the custom Crawler/Hulk geometry and animations.

## Aimed identity and health display

Managed walkers receive persistent, autogenerated first and last names. Names and health are hidden by default. When a player aims at a managed zombie within the configured range, a small floating name and health bar appear for that player only. Looking away or changing target hides the display again.

The check runs once per player every three ticks by default. It does not scan all zombies in a horde or perform per-zombie line-of-sight checks. The old attacker-only chat health messages have been removed.

## Existing systems retained

- Persistent daylight-immune walkers with a durable global admission budget.
- Configurable natural mob pass-through rates; non-zombie hostile mobs are blocked for all spawn reasons except admin commands and player spawn eggs.
- Vanilla spawner policy: ALLOW_ALL or CONVERT_TO_ZOMBIES. Converted spawners use proximity waves, nearby caps, and floating countdowns.
- Persistent shared virtual hordes with sound-sensitive migration, physical emergence only in unobserved chunks, and per-player arrival directions, estimated ETA, population, and temperament.
- Scragglers with independent local wander goals that may join a nearby shared horde.
- Blood Moon event schedule, warnings, and waves.
- Optional Metropolis BUILD population records.

## Repositories

- Dead Streets: this repository.
- Metropolis exporter integration: separate development branch in the Metropolis repository. No Metropolis assets or source are copied into this repository.

## Build and verification

Run bash test_core.sh with Java 25. Build with mvn -B -ntp clean package. Paper is the only compile-time server dependency; BetterModel is integrated through its optional runtime API.

CI starts Paper 26.2 without BetterModel to prove that the optional dependency does not prevent startup. It checks native Crawler/Hulk entity state and that both Blockbench models and the aimed identity system are packaged. A connected client with the BetterModel pack accepted is still needed to judge the actual appearance and animation. Test on a disposable world first.
